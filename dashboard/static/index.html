How to read these charts
  1. Real update. The hospital's trained weights (model parameters), tiny numbers near zero.
  2. Scaled to whole numbers (quantization: rounding to integers so masks can be added exactly). Without masking, every value lands in a thin sliver of the number line, so the server could read each one.
  3. Masked. Random masks are added modulo 2³² (modular arithmetic: wrap-around, like a clock). The values now fill the whole range. The server cannot tell them from random numbers.
  4. Only the sum is recoverable. After the unmask stage the server can recover the combined update of all hospitals, and nothing about one hospital alone.

How it works, and what it does not do

The pipeline for one round

Dashed return path: the new global model goes back down and the next round starts. Only model updates ever travel, never patient rows.

Threat model

Honest-but-curious server (it follows the protocol exactly but tries to read each hospital's update). Against that server:

  • SecAgg+ hides each single update: the server only learns the sum of all updates.
  • DP-SGD (differentially private training) limits what even the sum, i.e. the released model, can reveal about one patient. Its strength is the ε you see above.

The two protections cover different leaks, so the demo uses both.

Limits (read these before trusting the demo)

  • One machine. The four hospitals are simulated in one process on one computer, so this shows the protocol, not network security.
  • Collusion. With 4 hospitals, if 3 of them work with the server, the 4th hospital's update is revealed (sum minus the three known updates).
  • SecAgg does not replace DP. Masks hide single updates only inside the sum. The released model still needs differential privacy.
  • Large ε. The hospitals are small, so ε is large (see the epsilon bands above). The privacy cost shows up in ε, not in accuracy.
  • Clipping. Values beyond ±8 after scaling are silently clipped; each run asserts that the largest weight stays below 8.
  • Demo-grade library details. Flower's SecAgg+ (rounding, key handling) is not an audited production implementation.
